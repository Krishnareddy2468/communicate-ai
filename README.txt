HOW TO PUT IT ONLINE (needed for install + offline + microphone)
1. Upload ALL files in this folder (keep the "icons" folder) to any HTTPS host:
   Netlify Drop (drag the folder onto app.netlify.com/drop), GitHub Pages, or the school website.
2. Open the link in Chrome on Android -> tap "Install" (or menu -> Install app).
   iPhone: Safari -> Share -> Add to Home Screen.

SCHOOL LOGO
- In the app: Settings (gear icon) -> Upload logo. It appears on the splash screen,
  header, About page, footer and install banner on that device.
- To make the logo the INSTALLED APP ICON for everyone: replace the PNGs in /icons
  (icon-192.png, icon-512.png, maskable-512.png, apple-touch-icon.png) with the logo
  at the same sizes, then re-upload.
